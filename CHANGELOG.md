# Changelog

All notable changes to the **AssetOps** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-13

### Added
- Project architectural foundation and standardized documentation suite in `docs/`.
- Master Product Requirements Document (`docs/PRD.md`) defining post-issuance servicing requirements.
- Master Smart-Contract Design (`docs/CONTRACT_DESIGN.md`) detailing `SecurityToken`, `CorporateActionRegistry`, `PaymentExecutor`, and `PaymentCurrency`.
- Monorepo directory structure: `contracts/`, `frontend/`, `backend/`, `scripts/`, `tests/`, `deployments/`, `.agents/`, and `.github/`.
- Architecture Decision Records (`docs/DECISIONS.md`) defining ADR-001 through ADR-030.
- Three-member engineering roles: Smart Contract Lead, Protocol/Backend Lead, and Product/Frontend Lead.
