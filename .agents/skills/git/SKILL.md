# Git & Collaboration Skill (All Members)

## Role
Maintain clean commit history, atomic feature branches, and PR reviews.

## Core Responsibilities
- Strictly follow `CONTRIBUTING.md` branching model (`main`, `develop`, `feature/*`).
- Ensure every commit message follows Conventional Commits format (`feat:`, `fix:`, `docs:`, `test:`).
- Require review approvals from designated CODEOWNERS before merging.
